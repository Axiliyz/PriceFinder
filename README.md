# PriceFinder

Десктоп-приложение на Python для загрузки и поиска по прайс-листам в формате Excel. Решает частую боль с "грязными" прайсами: разные кодировки, разные форматы файлов, произвольное расположение столбцов с названием и ценой.

## Возможности

- Чтение `.xlsx` / `.xls` с автоматическим перебором движков (`openpyxl`, `xlrd`, `python-calamine`) — если один не смог открыть файл, пробуется следующий
- Автоматическое исправление "кракозябр" в кириллице (неверно декодированной кодировки)
- Эвристическое определение столбцов с названием товара и ценой без жёсткой привязки к структуре файла
- Поиск по названию среди загруженных прайсов
- Экспорт результата в CSV

## Стек

Python, [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) (UI), pandas, openpyxl / xlrd / python-calamine.

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

## Сборка в исполняемый файл

CI-пайплайны (`.github/workflows`) собирают приложение через PyInstaller для Windows и macOS по тегу релиза (`v*`) или вручную.

## Как это работает

Самая нетривиальная часть — определение, какие столбцы в файле отвечают за название товара и цену, когда структура прайса заранее неизвестна. Логика в `app.py`:

- `select_name_price_columns_from_data` — скоринг столбцов по плотности кириллических символов (вероятный столбец с названием) и по плотности чисел (вероятный столбец с ценой)
- `choose_header_earliest_near_best` — поиск строки заголовка, даже если реальные данные начинаются не с первой строки листа
